# Cookie Run 打怪賽雕刻召喚石釘選策略評估

這是一個不需要安裝套件或啟動伺服器的純靜態網站，主頁用來評估召喚石釘選策略，第二頁可查詢遊戲截圖中的附加能力與機率。

## 本機使用

直接以 Chrome 開啟 `index.html` 即可。網站不會連線到外部服務，搜尋與篩選都在瀏覽器內完成。

## 功能

- 以表格列出 19 個附加能力群組與 187 筆截圖可見項目。
- 支援即時關鍵字搜尋，可輸入多個關鍵字。
- 支援指定群組篩選，以及「只看 ★ 推薦能力」快速篩選。
- 「釘選策略評估」可依序選擇群組 19 紫字、任意藍字及 1～3 個白字能力，並指定其中任意 2 個已設定欄位為已釘選。
- 依剩餘 3 格精確計算單次達成率、期望次數與期望花費，且會排除已選能力的重複群組。
- 試算結果代表目前兩格已釘後的終局成本，不包含取得釘選內容或中途換釘的前置成本；指定白字出現後，通常應由紫＋藍切換為藍＋白。
- 能力輸入使用自製搜尋下拉選單，支援聚焦顯示、模糊搜尋、全半形符號與鍵盤選取。
- 高級能力以紫色顯示，中級能力以藍色顯示；文字資料中以 `*` 開頭的 43 筆項目會標記為中級。
- 文字資料中以 `**` 開頭的 9 筆（推薦藍字／中級）與以 `#` 開頭的 24 筆（推薦白字／低級）會加上 ★ 推薦標記，合計 33 筆。可用核取方塊只看推薦能力，或搜尋「推薦藍字」「推薦白字」分別篩出。
- 藍字與白字提供排除已占用群組後的完整能力列表，★ 僅作推薦標記；設定 1 個白字即可試算，另外 2 個白字為選填。
- 桌面版使用固定表頭，手機版自動改為卡片式列表。
- 按 `/` 可快速聚焦搜尋欄，按 `Esc` 可清除搜尋條件。

## GitHub Pages 部署

1. 將整個目錄提交到 GitHub 儲存庫。
2. 在儲存庫的 **Settings → Pages** 選擇 **Deploy from a branch**。
3. 選擇 `main` 分支與 `/ (root)` 目錄後儲存。
4. 等待 GitHub Pages 完成部署，即可使用儲存庫提供的網址開啟。

網站使用相對路徑載入樣式與程式，因此可直接部署在 GitHub Pages 的專案子路徑下。

### 後續更新

完成第一次 GitHub 與 Pages 設定後，直接雙擊 `更新網站.bat`。它會呼叫純英文編碼的 `update-site.bat`，檢查網站檔案是否有變更，建立 Git 紀錄並推送到 `main` 分支；`pic` 原始截圖、文字資料及測試檔案不會被加入。

## 檔案說明

- `index.html`：頁面結構與文字內容。
- `styles.css`：桌面、手機與列印樣式。
- `script.js`：遊戲參數資料、搜尋與群組篩選邏輯。
- `更新網站.bat`：方便雙擊使用的網站更新啟動器。
- `update-site.bat`：將網站更新提交並推送到 GitHub 的核心批次檔。
- `遊戲參數整理.txt`：原始文字整理資料。行首標記：`*` ＝中級（藍字）能力，`**` ＝想要的推薦藍字，`#` ＝想要的推薦白字（低級）。網站資料以此為準，修改後請重跑煙霧測試確認兩邊一致。
- `釘選策略分析.md`：釘選順序與機率推導的分析紀錄。
- `tests/smoke-test.js`：不需額外套件的核心功能煙霧測試。

## 驗證

若電腦已安裝 Node.js，可執行：

```powershell
node .\tests\smoke-test.js
```
